**Creator Accessories** — gimbals, wireless mics, RGB lights, mounts  
Target audience: TikTok/Instagram/YouTube creators aged 18–35  
Average Order Value (AOV): ~$65  
Profit margin target: 40–60% after COGS + ads

## 🚀 Getting Traffic Fast (First 30 Days)

### Priority 1: TikTok Organic (FREE — Start Day 1)

The fastest zero-cost traffic. Creator tools are perfect for TikTok.

**Content formula that converts:**
1. **Problem hook** (0–2 sec): "Why does my footage always look shaky?" 
2. **Product reveal** (2–5 sec): Show the gimbal in action
3. **Before/After** (5–12 sec): Bad footage vs. buttery-smooth footage
4. **CTA** (12–15 sec): "Link in bio → lumagear.com"

**Post 1x per day minimum.** Test 5 different hooks in the first week.

**Hashtags:** #contentcreator #creatortips #gimbaltips #videography #tiktoktools

---

### Priority 2: TikTok Paid Ads (Start at $30/day after first sale)

**Campaign structure:**
- Create 5–10 ad creatives per product (use product demo + hook variations)
- Target: 18–34, interests: content creation, photography, YouTube, social media
- Start budget: $20–30/day per ad set
- Test 3–5 days → pause losers → scale winner (increase budget 20–30% every 2 days)
- **Key metric:** Target ROAS of 2.5x minimum before scaling

**Winning creative format:**
- 9:16 vertical, 15 seconds max
- Native/authentic feel (NOT polished brand ads)
- Show the product solving a real problem
- Use trending audio

---

### Priority 3: Meta Ads (Facebook/Instagram)

- Duplicate winning TikTok creatives for Meta (tweak aspect ratio to 4:5)
- Lookalike audiences from email list (once you have 100+ orders)
- Retarget cart abandoners with 10% off discount code
- Budget: Start $20/day on Instagram placements

---

### Priority 4: SEO (Long-term, 3–6 months)

Target keywords:
- "best AI phone gimbal 2026" (high intent, medium competition)
- "wireless lapel microphone for iPhone"
- "foldable ring light for creators"
- "MagSafe tripod mount"

Add a blog section to the site. One article per week minimum.

## 📧 Email Capture & Automation

**Pop-up offer:** 10% off first order for email sign-up  
**Recommended tools:** Klaviyo (free up to 250 contacts) or Mailchimp

**Automated flows to set up:**
1. **Welcome series** (3 emails over 7 days) → brand story + best sellers
2. **Abandoned cart** (3 emails: 1hr / 24hr / 48hr) → recover lost sales (avg 15% recovery)
3. **Post-purchase** (Day 3 + Day 14) → review request + upsell
4. **Win-back** (60 days no purchase) → 15% off coupon

## 🚀 Deployment

### Deploy to Vercel (Free — recommended)

```bash
# 1. Install Vercel CLI
npm install -g vercel

# 2. Deploy from the lumagear directory
cd ~/lumagear
vercel

# 3. Add environment variables in Vercel dashboard:
#    Settings → Environment Variables → paste from .env.local
```

### Custom Domain
Buy `lumagear.com` or `getlumagear.com` from Namecheap (~$10/year)  
Connect it in Vercel: Settings → Domains → Add Domain

## 🔑 Keys to Winning

1. **Move fast** — get the first TikTok up TODAY
2. **Volume test** — 10 content pieces that flop is better than waiting for 1 perfect one
3. **Double down on winners** — when a video gets traction, make 10 variations
4. **Protect your margin** — never discount more than 20% or run ads to a losing product
5. **Build the email list** — it's your only asset that doesn't depend on an algorithm
